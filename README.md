# Nostalgia Sentiment Analysis
Binary classification project to detect nostalgia in YouTube comments using transformer-based models.

# Overview
This project fine-tunes and compares two pre-trained language models on a nostalgia sentiment dataset, classifying comments as either nostalgic or not nostalgic.

# Dataset

Nostalgic Sentiment Analysis of YouTube Comments sourced from Hugging Face.

# Models
google-bert/bert-base-cased
FacebookAI/xlm-roberta-base

# Requirements
transformers
torch
datasets

# Usage
Open SEIDL_ProjectSentimentAnalysis-4.ipynb in Google Colab or Jupyter and run the cells in order.

For a detailed project description see "Computational Linguistics Project.pdf" in this repository.
